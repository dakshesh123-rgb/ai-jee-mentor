## 🎯 What is AI JEE Mentor?

Standard AI chatbots simply spit out final answers when given complex competitive exam problems (JEE Main / JEE Advanced). This leads to passive memorization rather than deep analytical mastery.

**AI JEE Mentor** inverts this paradigm through **Socratic Reasoning**:
1. **Multi-Modal Problem Intake:** Accepts handwritten notes, textbook photos, camera captures, and mathematical LaTeX inputs.
2. **First-Principles Breakdown:** Guides students step-by-step through free-body diagrams, conservation laws, and calculus integrations.
3. **Diagnostic Questioning:** When a student makes a mistake, the mentor pinpoints the exact conceptual misconception with targeted Socratic hints instead of handing over the solution.
4. **Structured Mathematical Output:** Clean LaTeX rendering for formulas, differential equations, and vectors.

## 💻 Local Development

Clone the repository and install dependencies using `pnpm`:

```bash
git clone https://github.com/dakshesh123-rgb/ai-jee-mentor.git
cd ai-jee-mentor
pnpm install
pnpm build
```

To run the local development server:

```bash
cd src/frontend
pnpm dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.
